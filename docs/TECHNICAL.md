# Техническая записка

## 1. Архитектура

```
GameBootstrap (RuntimeInitializeOnLoadMethod)
  └── GameRoot (синглтон, DontDestroyOnLoad)
        ├── Camera + CameraRig + PostFx (URP Volume)
        ├── Canvas
        │     ├── MenuScreen      (выбор самоката/карты/режима)
        │     └── GameLayer
        │           ├── Hud            (спидометр, батарея, режим, привод, дистанция, время, очки, комбо)
        │           └── TouchControls  (экранные кнопки → TouchState)
        ├── InputController (клавиатура + TouchState → PlayerInput)
        ├── WorldContext (TrackMap | CityMap + свет + чекпоинты)
        ├── ScooterController (Rigidbody + 2 × WheelCollider)
        │     └── WheelieController
        └── TrickSystem (очки, комбо)
```

Ключевое решение: **ничего не хранится в ассетах**. Сцена пустая, весь контент строится в рантайме.
Причины: нет бинарных ассетов в репозитории, нет риска сломанных GUID/префабов, детерминированная сборка.

## 2. Физика самоката

### 2.1 Основа
`Rigidbody` (масса = масса самоката, центр масс 0.42 м над землёй — низко, как у реальной деки) +
два `WheelCollider` (передний/задний) с пружинной подвеской:
`spring 32 000 Н/м`, `damper 3 400`, `suspensionDistance 0.09 м`, `targetPosition 0.45`.
`Rigidbody.ConfigureVehicleSubsteps(5, 12, 15)` — стабилизация колёс на высокой скорости.

### 2.2 Привод
Мощность ограничивает силу тяги: `F = min(P·N / max(|v|, 1.5), F_max·N)`, момент `M = F · r`.
`N` — число активных моторов (1 для RWD, 2 для AWD). Вблизи максимальной скорости режима
включается спад (taper) 90 % → 100 % от лимита. Момент нарастает не мгновенно:
`MoveTowards(M, target, MotorRampRate · TorqueCeiling · dt)`.

Топ-скорость определяется балансом мощности и сопротивления:
аэродинамика `F_drag = 0.16 · v²`, качение `0.5 Н·м / r ≈ 3.6 Н`.
Для 2000 Вт это даёт ≈ 19.4 м/с, что совпадает с паспортными 70 км/ч — поэтому 4-й «режим» не нужен.

### 2.3 Тормоза и рекуперация
Передний и задний контуры независимы: `brakeTorque = MaxBrakeTorque · input` (задний × 0.85).
Электронный тормоз работает при отпущенном газе: `RegenBrakeTorque` на заднее колесо + заряд:
`ΔE = (F_regen · v · η) · dt`, `η = 0.55`. Расход считается как `F_тяги · v / КПД 0.80` + потери на разгон.

Ограничение физики: сцепление шины не даёт замедления больше ≈ 1 g, поэтому «4 м с 70 км/ч» недостижимы
(нужно 4.8 g). Значение `MaxBrakeTorque = 62 Н·м` соответствует ≈ 12 м/с² — на пределе сцепления.

### 2.4 Баланс (искусственный «райдер»)
Двухколёсный самокат без райдера физически падает, поэтому добавлен PD-регулятор:

* **Крен:** целевой угол = `-steer · 21° · clamp(|v| / 14)`, момент
  `M = (target - roll)·260 - rollRate·46`, ограничение ±520 Н·м.
* **Тангаж:** цель — угол наклона грунта под колёсами (по нормали контакта), чтобы самокат «лежал» на трамплине.
  `M = (target - pitch)·120 - pitchRate·26`.
* **Рыскание:** слабое демпфирование `-yawRate·6`, чтобы трение шин не раскручивало самокат.

При жёстком торможении только передним (input > 0.8 и v > 30 км/ч) коэффициент тангажа снижается вдвое —
поэтому продолжительное переднее торможение реально приводит к endo.

### 2.5 Wheelie
`WheelieController` включается при удержании кнопки и `v > 15 км/ч`.

* Целевой угол: `eq · (0.55 + 0.45·throttle) + lean·34° + (throttle > 0.85 ? 5 : 0)`, где `eq = 37°` (G4) / `39°` (F3).
* Подъём не мгновенный: цель умножается на `liftProgress`, который растёт за
  `LiftTime · lerp(1.7, 0.75, |v|)`; в AWD время умножается на 1.55 (передний мотор тянет нос вниз).
* Момент: `M = m·g·0.40·cos(pitch) + (target - pitch)·K - pitchRate·D`, ограничение ±`WheelieMaxTorque`.
  `K = 128` (G4, слабое демпфирование `D = 7.5` — «балансировать сложнее»), `K = 168`, `D = 14` у F3 (стабильнее).
* Зона баланса 25–55°, опасная > 60°, **loop out > 72°** → падение.
* Газ поднимает (коэффициент 0.45), сброс опускает (до 0.55·eq), наклон корпуса ±34° — так можно дойти до loop out.

### 2.6 Падения и респавн
Причины: pitch > 72° в wheelie, |roll| > 62°, pitch < -26° (endo), столкновение с препятствием
при относительной скорости > 7.5 м/с и нормали контакта не «вверх». После падения управление отключается,
кузову даётся толчок, через 2.4 с — респавн на последнем чекпоинте (батарея и очки сохраняются).

## 3. Тюнинг

| Параметр | Файл | Значение |
|---|---|---|
| Гравитация | `GameConfig.Gravity` | −14 м/с² |
| Коэффициенты баланса | `VehicleTuning` | см. §2.4 |
| Мощность/тяга/моменты | `ScooterSpec` | на самокат |
| Углы wheelie | `VehicleTuning.LoopOutAngle`, `WheelieController.BalanceMin/MaxAngle` | 72° / 25° / 55° |
| Расход батареи | `GameConfig.BatteryDrainMultiplier` | 6 |
| Постобработка | `GameConfig.PostProcessingEnabled`, `PostFx` | bloom всегда |

Все значения — стартовые; подбирались аналитически (момент инерции ≈ 4.5 кг·м² по габаритам,
гравитационный момент ≈ `m·g·0.40`), финальная доводка требует игры на устройстве.

## 4. Сборка

1. `ProjectSetup` (`[InitializeOnLoad]`) при открытии проекта:
   PlayerSettings (имя, bundle id, IL2CPP, ARM64, minSdk 24, OpenGLES3, landscape, Linear),
   сцена в Build Settings, создание URP-ассета через `ScriptableObject.CreateInstance` + `SerializedObject`
   (имя типа ищется рефлексией — нет жёсткой привязки к API конкретной версии URP),
   добавление `URP/Lit`, `URP/Unlit`, `Standard` в **Always Included Shaders**.
2. GameCI (`game-ci/unity-builder@v4`) собирает Android APK в `build/Android`, workflow кладёт его в артефакт.
3. Локально: `BuildScript.BuildAndroid` (`-executeMethod`).

### Почему Always Included Shaders критично
Материалы создаются в рантайме, ни один ассет их не ссылается. Без явного включения шейдеров
Unity вырезал бы `URP/Lit` из билда, `Shader.Find` вернул бы `null`, и вся сцена стала бы розовой.

### Почему URP-ассет создаётся кодом
Рукописный `.asset` для URP содержит десятки полей, зависящих от версии пакета; ошибка в них ломает
рендер. Создание через API даёт объект, заполненный самим Unity, а `GraphicsSettings.defaultRenderPipeline`
и `QualitySettings.renderPipeline` назначаются в коде. Если создать не удалось — игра остаётся играбельной
на встроенном пайплайне (`MaterialLibrary` выбирает `Standard` по факту активного пайплайна).

## 5. Риски и что с ними делать

| Риск | Митигация | Что проверить при первом прогоне |
|---|---|---|
| URP-ассет не создался (изменились имена типов/полей) | рефлексия + fallback на Standard, лог-варнинг | ищите в логе `[ProjectSetup] URP asset is unavailable` |
| Настройки не применились к сборке | установка в `[InitializeOnLoad]` + `AssetDatabase.SaveAssets()` | `PlayerSettings` в логе билда |
| Лицензия/секреты | документировано в README | ошибка активации в шаге Build |
| Пустая сцена не в Build Settings | `ProjectSetup.EnsureBuildScenes` + `EditorBuildSettings.asset` в репозитории | список сцен в логе |
| Jitter подвески на слабых устройствах | `ConfigureVehicleSubsteps`, подшаги | визуально на телефоне |
| Слишком много источников света в городе | 6 фонарей без теней, 2 фары, солнце | просадка FPS в городе |

## 6. Smoke-чеклист (после установки APK)

1. Меню: обе карточки самокатов открываются, «БЕСПЛАТНО» видно, СТАРТ запускает заезд.
2. Самокат стоит на дороге, не проваливается; газ/тормоза/руль работают, спидометр растёт до 70 (G4) / 66 (F3).
3. «ПРИВОД» у G4 ничего не меняет, у F3 переключает AWD/RWD и индикатор меняется.
4. Wheelie: до 15 км/ч не поднимается; выше — плавный подъём; высота носа идёт за газом
   (больше газ — выше), шкала pitch просто показывает угол, «зелёной зоны» нет.
5. Полный газ + «НОС ↑» → loop out → баннер «ПАДЕНИЕ» → респавн.
6. Только передний тормоз на 50+ км/ч → endo/стоппи.
7. Time Attack: ворота идут по порядку, таймер, финиш на 5-м.
8. Город: лестницы/перила/стройка на месте, фары машин двигаются.
