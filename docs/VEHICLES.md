# Самокаты: паспортные данные и игровая реализация

Оба самоката **бесплатны** и доступны с первого запуска — без доната, покупок и разблокировки.

## KugooKirin G4 (2026)

| Параметр | Значение |
|---|---|
| Привод | **только задний (RWD)**, один мотор |
| Мощность | 2000 Вт (пик 2400 Вт) |
| Макс. скорость | 70 км/ч |
| Запас хода | до 75 км |
| Батарея | 60V 20Ah = 1200 Вт·ч |
| Колёса | 11″ внедорожные пневматические (r = 0.1397 м) |
| Тормоза | передний и задний дисковые |
| Подвеска | регулируемая двойная |
| Вес | 37 кг |
| Нагрузка | 120 кг |
| Режимы | 1) 20 км/ч 2) 40 км/ч 3) 70 км/ч |
| Оснащение | LCD, фара, стоп-сигнал, поворотники, ключ зажигания |

В игре: `ScooterSpec.CreateG4()`. Колёсная база 1.06 м, дека 510×220 мм, максимальная тяга 320 Н,
тормозной момент 62 Н·м, рекуперация 8 Н·м, сцепление на асфальте 1.85 / на грунте 0.95 (пробуксовка RWD).

Wheelie: подъём 0.75 с (быстрее с ростом скорости), K = 128, D = 7.5 — **легче поднять, сложнее балансировать**.

## Kugoo F3 Pro Max

| Параметр | Значение |
|---|---|
| Привод | **полный (AWD)**, передний + задний моторы, переключатель AWD ⇄ RWD |
| Мощность | 2 × 1100 Вт = 2200 Вт |
| Макс. скорость | 68 км/ч |
| Запас хода | до 70 км |
| Батарея | 52V 23.4Ah = 1216.8 Вт·ч |
| Колёса | 10″ пневматические бескамерные (r = 0.127 м) |
| Тормоза | передний + задний дисковые + электронный тормоз |
| Подвеска | передняя и задняя амортизация |
| Вес | 32.5 кг (в паспорте 32.5–41 кг в зависимости от версии) |
| Нагрузка | 130 кг |
| Режимы | 1) 30 км/ч 2) 51 км/ч 3) 66 км/ч |
| Оснащение | LCD, переключатель AWD/RWD, фара, стоп-сигнал, габариты |

В игре: `ScooterSpec.CreateF3ProMax()`. Колёсная база 1.0 м, тяга 150 Н на мотор (300 Н в AWD / 150 Н в RWD),
тормозной момент 58 Н·м, сцепление 1.9 / 1.0.

Wheelie: подъём 0.8 с × 1.55 в AWD (передний мотор тянет нос вниз), K = 168, D = 14 —
**тяжелее поднять, но баланс стабильнее**; в RWD — почти как G4.

## Как соотносятся модели в игре

| Сценарий | G4 | F3 Pro Max |
|---|---|---|
| Старт со светофора | 320 Н на одном колесе — больше пробуксовки | 300 Н на двух колёсах — лучше сцепление |
| Прямая, максимальная скорость | 70 км/ч, мощность 2000 Вт | 66 км/ч в 3-м режиме, 2200 Вт в AWD |
| Расход батареи | 1200 Вт·ч | 1217 Вт·ч, в AWD расход выше |
| Бездорожье | RWD, сцепление хуже | AWD держит лучше |
| Wheelie | легче, но капризнее | стабильнее, но поднимать дольше |

## Источник данных

Характеристики взяты из технического задания пользователя (паспортные данные моделей 2025–2026).
Где паспорт даёт диапазон (вес F3 32.5–41 кг), в симуляции используется нижняя граница — она соответствует
версии с меньшей батареей и лучше согласуется с заявленной максимальной скоростью.
