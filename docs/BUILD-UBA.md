# APK без лицензии и без секретов — Unity Build Automation (UBA)

Этот путь сохраняет Unity и URP, но убирает ровно ту вещь, на которой всё встало: **файл лицензии**.
Сборку выполняют машины Unity, они же берут лицензию с вашего аккаунта. Никакого Unity Hub, `.ulf`,
VNC-десктопа, кодов и токенов не нужно — только браузер телефона.

Проверено по документации Unity (ноябрь 2026):

- Build Automation поддерживает Git-репозитории; **если репозиторий публичный, он подключается автоматически**,
  токен не требуется (наш `WeteroScript/Game` публичный).
- Для Android нужны Bundle ID и keystore; есть вариант **«Auto-generated debug keystore (for development only)»** —
  значит и keystore-секретов не нужно.
- Бесплатный лимит — **200 минут build-машин в месяц** (обновляется ежемесячно). Одна сборка этого проекта —
  примерно 10–25 минут.

## Шаги (всё в браузере)

1. <https://cloud.unity.com> → вход тем же Unity ID.
2. Создайте **организацию**, если её нет (имя любое, роль — владелец). Это бесплатно.
3. В организации: **DevOps → Build Automation → Get started / New project**.
4. **Source control**: выберите **GitHub** → репозиторий `WeteroScript/Game`.
   Публичный репозиторий подключается без токена. Если попросит токен — создайте classic PAT
   с галочкой `public_repo` (<https://github.com/settings/tokens>), вставьте и авторизуйте.
5. **Build target**:
   - **Target name**: `android-apk`
   - **Branch**: `arena/c7d56f15-game` (после слияния в `main` — `main`)
   - **Project subfolder**: пусто (Assets и ProjectSettings лежат в корне)
   - **Unity version**: **2022.3.22f1** — именно она в `ProjectSettings/ProjectVersion.txt`.
     Если такой версии в списке нет — возьмите ближайшую 2022.3.x и напишите мне, я поправлю `ProjectVersion.txt`.
   - **Platform**: **Android**, **Build type / Export type**: **APK** (не AAB!)
6. **Credentials** (Android):
   - **Bundle ID**: `com.weteroscript.kugoowheelie` — тот же, что в проекте.
   - **Credentials set**: **Auto-generated debug keystore (for development only)**.
7. **Build method**: оставьте пустым (UBA соберёт сцены из Build Settings; проект настраивает их сам через
   `Assets/Editor/ProjectSetup.cs` при открытии).
8. **Auto-build** можно включить сразу: тогда каждый push в выбранную ветку даёт новый APK.
9. Нажмите **Build / Start build**. Через 10–25 минут: **Build history → выбранная сборка → Artifacts → APK**
   → скачивается прямо на телефон.

## Что важно помнить

- Android-сборка идёт на **Windows**-машине Unity (это и есть бесплатные 200 минут).
- Это отступление от требования «GitHub Actions + GameCI»: сборка в облаке Unity. Workflow
  `.github/workflows/android-build.yml` остаётся в репозитории и заработает, если когда-нибудь появятся секреты.
- Если UBA попросит «платёжный аккаунт» — не вводите карту: бесплатные минуты должны работать без неё;
  в этом случае напишите мне, разберёмся по тексту ошибки.
- Лог сборки полностью доступен в браузере — если что-то упадёт, пришлите первые 30 строк с ошибкой
  (`error CS…`, `Build failed…`).

## Если и это не сработает

Тогда остаётся единственный путь вообще без Unity — порт игры на **Godot 4**:

- лицензий нет вообще (MIT), Android-APK собирается в GitHub Actions **без единого секрета**;
- но это переписывание: ~5 800 строк C# → ~2 500–3 000 строк GDScript. Проект процедурный
  (модели из примитивов, физика на Rigidbody, мир строится кодом), поэтому порт механический;
- делается этапами, после каждого этапа — зелёная сборка: сначала физика самоката и камера,
  потом мир и трамплины, потом HUD/трюки, потом меню и две карты.
