# Можно ли собрать APK без трёх секретов Unity?

Короткий ответ: **без секретов — можно, но тогда это уже не GameCI.** Причина простая: сборка Unity
требует *активированной лицензии*, а лицензия — это учётные данные. Любой CI, который запускает
Unity, должен их откуда-то взять: либо из секретов GitHub, либо от самого Unity (их облако),
либо из уже активированной среды (Codespace, где вы вошли в Hub).

Ниже четыре реальных варианта, проверенных по документации, и честная цена каждого.

## Сравнение

| | Секреты в GitHub | Где собирается | Автоматизация | Цена |
|---|---|---|---|---|
| **A. GameCI в Actions** (текущий) | 3 (`UNITY_LICENSE`, `UNITY_EMAIL`, `UNITY_PASSWORD`) | GitHub Actions | полная: push/PR → APK | 0 ₽, минут Actions хватает |
| **B. Unity Build Automation** | **0** | облако Unity | полная: подключить репозиторий → автосборка по push | бесплатно 200 минут/мес (Windows), дальше платно |
| **C. Разовая сборка в Codespace** | **0** | Codespace, куда вы вошли в Hub | нет, руками один раз | 0 ₽ в рамках квоты Codespaces |
| **D. Сменить движок** (Godot/Defold) | 0 | где угодно | полная | 0 ₽, но это уже не Unity/URP |

## A. GameCI — как сейчас

Секреты нужны все три; одним `.ulf` не обойтись: для Personal-лицензии билдер активирует её
e-mail/паролем, поэтому `UNITY_EMAIL` и `UNITY_PASSWORD` тоже обязательны.
Плюс: полностью соответствует ТЗ, ничего больше настраивать не нужно. Минус: 15 минут возни с `.ulf`.

## B. Unity Build Automation — без секретов вообще

Сборку делает облако Unity, авторизация — обычный вход в аккаунт в браузере. GitHub секретов не касается.

1. <https://cloud.unity.com> → **DevOps → Build Automation** → подключить GitHub-репозиторий
   `WeteroScript/Game` (выдать доступ к репозиторию, ветку — `main`).
2. Создать **build target**: платформа **Android**, цель `APK`, Unity-версия **2022.3.22f1**.
3. Нажать **Build**. Дальше можно включить автосборку по каждому push.
4. APK скачивается со страницы сборки (или из Artifacts в Unity Cloud) прямо на телефон.

Что важно знать:

- бесплатный лимит — **200 минут build-машин в месяц** (обновляется ежемесячно); сборка этого проекта
  занимает ~10–25 минут, то есть ~8–15 сборок в месяц бесплатно;
- в Unity Cloud нужно будет создать организацию и принять условия — это делается с телефона;
- минус: это отступление от требования «GitHub Actions + GameCI» (сборка в другом облаке).
  Репозиторий при этом не меняется: `.github/workflows/android-build.yml` остаётся на месте и
  продолжит работать, если секреты когда-нибудь появятся.

## C. Один раз собрать в Codespace, где лицензия уже активна

В Codespace вы всё равно входите в Unity Hub — значит лицензия там активна, и редактор может собрать APK
в `-batchmode`, без всяких секретов. APK забирается файлом на телефон.

Почему это «на крайний случай»:

- нужно скачать ~9 ГБ (Editor 2022.3 + Android-модуль + SDK/NDK) на 2 ядра — это 40–90 минут;
- Android-модуль для Linux Unity официально публикует как macOS-`.pkg`, который приходится распаковывать
  `7z`+`cpio` — рабочий, но хрупкий путь (так делают docker-образы GameCI);
- это разовая ручная операция: следующий APK после правок снова придётся собирать руками.

## D. Не Unity

Godot 4 или Defold собирают Android-APK вообще без лицензий и секретов (Godot — MIT, Defold — свой
бесплатный build-сервер). Но игру пришлось бы переписать с нуля, а ТЗ требует Unity + URP.
Поэтому вариант упомянут только для полноты: технически это единственный способ «совсем без Unity-аккаунта».

## Что я советую

- **Один APK нужен «прямо сейчас»** → вариант **C** (я подготовлю скрипт сборки под Codespace).
- **Нужен регулярный APK после каждой правки, но без секретов** → вариант **B**; это 10 минут настройки
  в браузере телефона и полная автоматизация дальше.
- **Максимально по ТЗ** → вариант **A**, те самые 15 минут с `.ulf`.

Проверено по источникам: официальная страница цен Unity DevOps (200 бесплатных минут build-машин в месяц,
обновляются ежемесячно) и документация GameCI (для Personal нужны все три секрета).
