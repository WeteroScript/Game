## Закрыто в последних прогонах

1. **Приборка** — кромка корпуса скруглена радиусом 5 мм по всему периметру (добавленное тонкое сечение лофта давало «рифление», откатил — радиус делает то же без артефактов).
2. **Фара** — отражатель стал тёмным (`_m_black_d`), диоды 12.5×12.5 мм за прозрачным стеклом: планка больше не «белая полоса», читаются 6 светящихся окон, как на фото.
3. **Обод** — `FaceRing` переведён с плоского кольца на профиль полки с фаской (6 точек профиля: 86 → 94 → 97.5 → 98.2 → 95 мм, высота 12.4…19.0 мм).
4. **Проушины амортизатора** — добавлены резиновые втулки `DamperBushTop/Bot` Ø22.4/23.2 мм, выступающие за корпус проушины с обеих сторон.
5. **Шильдик амортизатора** — `DamperLabel` 2×20×14 мм на корпусе переднего амортизатора.
6. **Кронштейн подножки** — два болта `BracketBolt` М7 с внутренней стороны.

## Что ещё расходится (план добивки)

1. **Пиктограммы у кнопок приборки** — у оригинала 3 значка (питание/режим/свет), у нас только утопленные кнопки.
2. **Шильдик «G4»/наклейка на корпусе задних амортизаторов** — есть только спереди.
3. **Пропорции по точкам** — сверить база 0.905 м ↔ дека ↔ руль 0.962 м с фото (нужно орто-наложение по силуэту).
4. **Торец крыла у заднего колеса** — на фото отбортовка шире и с плавным радиусом, у нас 12×20 мм прямых.
5. **Скоба суппорта** — на фото видна пружинная скоба-фиксатор колодок, у нас только болты.
