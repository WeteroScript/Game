# Kugoo Freeride — Android-игра про электросамокаты (Godot 4)

Игра для **Android**, результат — устанавливаемый **`.apk`**. Движок — **Godot 4.3** (GDScript),
сборка идёт в **GitHub Actions** при каждом пуше: ни Unity, ни лицензий, ни секретов не нужно.

Играбельно сразу: меню → выбор самоката (оба бесплатны, доступны с первого запуска) → карта → режим → езда.

---

## 1. Как получить APK (можно всё с телефона)

**Самый простой путь:** вкладка **Releases** → последний релиз `Kugoo Freeride APK …` →
файл `KugooFreeride.apk` → откройте его на телефоне и установите.
Релиз создаётся автоматически при каждом пуше в `main`.

**Через Actions (артефакт):**

1. Откройте **Actions** в репозитории.
2. Workflow **«Build Android APK (Godot)»** запускается сам на каждый пуш в `main`
   (и на pull request). Вручную: **Run workflow**.
3. Дождитесь зелёной галочки (~5–8 минут).
4. Внизу страницы прогона: **Artifacts → `KugooFreeride-apk`** → скачайте архив, внутри `KugooFreeride.apk`.
5. Откройте APK на телефоне и установите (разрешите «Установка из неизвестных источников»).
   Артефакт приходит архивом — на телефоне его удобнее скачать через приложение GitHub,
   либо просто берите APK из **Releases**.

Сборку подписывает **отладочный keystore**, который workflow генерирует у себя же.
Такой APK ставится на телефон и играется, но не годится для Google Play (для магазина нужен свой keystore).

### Что делает workflow

`.github/workflows/godot-android.yml`:

| Шаг | Зачем |
|---|---|
| `chickensoft-games/setup-godot@v2` (4.3.0, + export templates) | ставит Godot и шаблоны экспорта |
| `actions/setup-java` (Temurin 17) + `android-actions/setup-android` | JDK и Android SDK |
| `sdkmanager` platform-tools / build-tools 34 / platform 34 | без них экспорт APK не работает |
| `keytool` → `/tmp/debug.keystore` | отладочная подпись |
| `godot --import` | импорт ресурсов проекта |
| `godot --check-only --script …` для каждого `.gd` | проверка синтаксиса всех скриптов |
| `godot --headless --fixed-fps 60 -- --smoke` | автотест: проезжает заезд за игрока и падает на ошибках |
| `godot --export-debug Android …` | собственно APK |
| `actions/upload-artifact@v4` | артефакт `KugooFreeride-apk` |

## 2. Управление

**Камера:** свайп по экрану (на телефоне) или перетаскивание мышью крутит обзор вокруг самоката;
через пару секунд без ввода камера сама возвращается за спину. Кнопка **ВИД** (или клавиша V/C)
переключает третье лицо и вид от первого лица — в первом лице камера тоже крутится свайпом.

**На телефоне (мультитач, можно держать газ и руль одновременно):**

| Кнопка | Действие |
|---|---|
| ◀ ▶ слева внизу | руль |
| ГАЗ справа внизу | тяга |
| ЗАД / ПЕРЕД справа | задний / передний тормоз |
| ВИЛЛИ (над газом) | одно нажатие разрешает подъём; нос встаёт только с газом, газ задаёт угол |
| РЕЖИМ | скорость 1 → 2 → 3 |
| AWD/RWD | привод F3 Pro Max (у G4 всегда задний) |
| РЕСПАУН | вернуть самокат на старт заезда |
| ВИД | третье лицо ⇄ первое лицо |
| МЕНЮ | пауза: «Продолжить» / «В меню» |

**Клавиатура (для проверки в редакторе/эмуляторе):**

| Клавиша | Действие |
|---|---|
| W / ↑ | газ |
| S / ↓ | задний тормоз |
| Left Shift | передний тормоз |
| A / D (←/→) | руль |
| Пробел / Left Ctrl | взвести вилли (поднимается вместе с газом) |
| V / C | третье лицо ⇄ первое лицо |
| Esc | пауза |
| мышь с зажатой ЛКМ | крутить камеру |
| Q / E | наклон корпуса назад / вперёд |
| Tab | переключить привод AWD ⇄ RWD |
| 1 / 2 / 3 | режим скорости |
| R | респаун |
| Esc | в меню |

## 3. Что в игре

**Самокаты (бесплатные, без доната):**

| | KugooKirin G4 (2026) | Kugoo F3 Pro Max |
|---|---|---|
| Привод | RWD, один задний хаб-мотор | AWD (2 × хаб-мотора), переключение AWD ⇄ RWD |
| Мощность | 2000 Вт (пик 2400) | 2 × 1100 = 2200 Вт |
| Макс. скорость | 70 км/ч | 68 км/ч |
| Режимы | 20 / 40 / 70 | 30 / 51 / 66 |
| Батарея | 60V 20Ah (1200 Вт·ч) | 52V 23.4Ah (1217 Вт·ч) |
| Колёса | 11″ внедорожные | 10″ бескамерные |
| Масса / нагрузка | 37 кг / 120 кг | 32.5 кг / 130 кг |
| Тормоза | передний + задний дисковые | дисковые + электронный тормоз |

**Wheelie:** только выше 15 км/ч, подъём не мгновенный (0.5–1.5 с, зависит от скорости и привода),
зона баланса 25–55°, слабая автокоррекция, критический угол >70° → loop out и падение.
G4 поднимается легче и балансируется хуже; F3 в AWD поднимается тяжелее, но баланс стабильнее,
в RWD — как G4.

**Тормоза:** раздельные передний/задний, электронный тормоз (рекуперация при сбросе газа с подзарядкой батареи).

**Карты:** «Ровная дорога» (идеально ровное шоссе 1.5 км: две полосы с разметкой,
отбойники с двух сторон и лес за ними) и «Город» (улицы, дома, лестницы, перила,
парковка, отбойники, фонари, зебры).

**Режимы:** свободная езда, Time Attack (5 минут на очки и дистанцию), Freestyle (90 с на очки).
**Трюки:** wheelie, stoppie, прыжки, вращения — очки и комбо-множитель до ×5.

**HUD:** скорость, режим с ограничением, привод, батарея (полоса и %), дистанция, время, очки и комбо.

**Модели:** самокат собран из настоящих узлов — дека с гриптейпом и боковыми молдингами,
аккумуляторный отсек, рулевая колонка со замком складывания, вилка, амортизаторы, двусторонний маятник, крылья с
брызговиком, колёса (покрышка-тор, обод, спицы, хаб-мотор), фара, стоп-сигнал, дисплей, шильдик.
**Райдер:** персонаж в шлеме с рюкзаком; руки через IK держатся за грипсы (руль поворачивается —
руки едут вместе с ним), колени сгибаются на торможении, корпус наклоняется в поворот, на вилли
райдер выпрямляется относительно земли, при падении руки разлетаются.

**Звук:** процедурный, без файлов — вой мотора (питч и громкость от скорости и газа), шум шин,
ветер, глухой удар при падении и «дзынь» за трюк.

## 4. Структура проекта

```
godot/                         ◀ рабочая игра, Godot 4
  project.godot                 настройки: гравитация 14, физика 60 Гц, mobile renderer
  scenes/main.tscn              единственная сцена, корень — Node3D с game.gd
  export_presets.cfg            пресет Android (arm64, APK, debug-keystore)
  scripts/
    game.gd                     оркестратор: меню → отсчёт → заезд → результаты
    game_config.gd              все константы (массы, моторы, тормоза, камера, таймеры)
    scooter_spec.gd             ТТХ двух самокатов
    scooter.gd                  физика: VehicleBody3D + ручная тяга/тормоза/рекуперация
    wheelie.gd                  вилли-защёлка: подъём, угол от газа, перегазовка и loop out
    scooter_model.gd            модель самоката: дека, вилка, крылья, колёса, фара
    rider_model.gd              персонаж-райдер с IK-руками и живой позой
    scooter_audio.gd            синтез звука (мотор, шины, ветер, удары)
    world_builder.gd            обе карты из примитивов
    camera_rig.gd               chase-камера и вид от первого лица, ручная орбита (мышь/свайп)
    pause_screen.gd             меню паузы: «Продолжить» и «В меню»
    trick_system.gd             очки и комбо
    hud.gd                      HUD + мультитач-кнопки
    menu_screen.gd              выбор самоката, карты, режима
    input_state.gd              клавиатура и сенсор, эдж-триггеры
    ui_factory.gd               мелкие хелперы UI
Assets/                        ◀ старый проект Unity 2022.3 (оставлен как справка, не собирается)
.github/workflows/
  godot-android.yml             сборка APK (актуальная)
  android-build.yml             старый Unity/GameCI-workflow (только ручной запуск)
docs/                          заметки, ТТХ, история (Unity-эпоха в TECHNICAL.md и др.)
```

Сцена намеренно почти пустая: мир, самокат, свет, интерфейс создаются в рантайме.
Так нет битых ассетов и конфликтов импорта.

## 5. Честные отклонения от ТЗ (важно)

1. **Тормозной путь 4 м с 70 км/ч физически невозможен.** 70 км/ч = 19.4 м/с; остановка за 4 м требует
   замедления ≈ 47 м/с² (≈ 4.8 g), а предел сцепления шины — около 1 g. В игре тормоза настроены на пределе
   сцепления (≈ 12 м/с², путь ≈ 16 м с 70 км/ч).
2. **3D-модели процедурные.** Собираются кодом из примитивов (рама, дека, колёса, вилка, руль, акценты),
   промпты для AI-генерации остались в `docs/MODELS.md`.
3. **Батарея расходуется ускоренно** (×6) — иначе заряда хватало бы на ~45 минут езды.
   Множитель: `GameConfig.BATTERY_DRAIN_MULTIPLIER`.
4. **Физика баланса аркадная.** Настоящий самокат без райдера падает; в игре работает PD-«балансир»
   крена и тангажа. Без него игра была бы непроходимой.
5. **Подпись APK — debug** (ставится на телефон, не для Google Play).
6. **Time Attack** считает очки за дистанцию/время, а не ворота по порядку — ворот-чекпоинтов в Godot-версии нет.
7. **Звук процедурный** — синтезируется кодом. Это не записи реального G4: вой мотора
   пилообразный с гармониками, шины и ветер — отфильтрованный шум. Замена на реальные
   сэмплы — это положить `.ogg` в `godot/audio/` и подставить в `scooter_audio.gd`.
8. **Endo** (падение через руль) срабатывает только от переднего тормоза на земле — иначе
   любой прыжок в городе засчитывался как падение.
9. Если игрок застрял в стене с полным газом 4 секунды или улетел за край карты —
   самокат сам возвращается на старт, чтобы заезд не вставал.

## 6. Что проверено в CI (а не на словах)

Последняя зелёная сборка (workflow «Build Android APK (Godot)») подтверждает:

* APK собирается, размер ≈ 24 МБ, артефакт `KugooFreeride-apk`;
* все 13 скриптов проходят `--check-only` без ошибок;
* автотест в headless-режиме проезжает заезд целиком, вот его числа:
  * **G4**: 0 → 36 км/ч, вилли по кнопке: нос встаёт за ~1 с и держится в зоне баланса
    (52–55°) даже без газа, газ задаёт угол; засчитано ~305 очков,
    комбо до ×2.2; перегазовка на высоком угле валит через заднее колесо;
  * **F3 Pro Max**: AWD ⇄ RWD переключается, 48 км/ч, за 90 секунд Freestyle — 1050 м,
    батарея 100 → 82 %, падений нет;
  * экран результатов появляется, когда таймер Freestyle дошёл до нуля.

### Скриншоты (как я проверяю внешний вид)

Отдельный job «Render model screenshots» рендерит игру под xvfb и публикует PNG в ветку
[`ci-screenshots`](https://github.com/WeteroScript/Game/tree/ci-screenshots/screenshots):
оба самоката с пяти ракурсов, экран меню, вид из камеры игрока и вилли.
Там же видно HUD и вёрстку кнопок — именно по этим картинкам правились модели и камера.

Ещё физика не на словах: цифры выше печатает сам движок в логе сборки, и бот закрепляет их
комментарием в пулл-реквесте.

## 7. Производительность (Android)

* Mobile-рендерер, ETC2/ASTC, 60 Гц физика, MSAA 2x, тени только у солнца.
* Процедурные низкополигональные меши, без текстур — нет тяжёлых материалов.
* Туман и glow дешёвые; постобработка отключается одной строкой в `game.gd` (`env.glow_enabled`).

## 8. Лицензия и товарные знаки

Код игры — учебный/демонстрационный проект. Названия Kugoo / KuKirin и характеристики самокатов
приведены как справочные данные; модели в игре — процедурные стилизации, не официальные ассеты бренда.
