# Kugoo Freeride — Android-игра про электросамокаты (Unity URP)

Игра для **Android**, собираемая в **.apk**. Это не сайт и не веб-приложение: проект — Unity 2022.3 LTS + URP,
сборка через **GitHub Actions / GameCI**, результат — устанавливаемый APK в артефактах Actions.

Играбельно сразу: меню → выбор самоката (оба **бесплатны** и доступны с первого запуска) → карта → режим → езда.

---

## 1. Как получить APK

1. В репозитории задайте секреты (**Settings → Secrets and variables → Actions**):

   | Секрет | Что это |
   |---|---|
   | `UNITY_LICENSE` | содержимое `.ulf`-файла лицензии Unity (Personal/Pro) |
   | `UNITY_EMAIL` | e-mail аккаунта Unity |
   | `UNITY_PASSWORD` | пароль аккаунта Unity |

   **Где это взять: [`docs/LICENSE.md`](docs/LICENSE.md).**
   **Если ПК нет вообще — [`docs/LICENSE-PHONE.md`](docs/LICENSE-PHONE.md):** весь путь с телефона,
   в облачном Codespace, который сам поднимает рабочий стол и Unity Hub (`.devcontainer` уже в репозитории).
   Кратко: Unity ID регистрируется с телефона; `.ulf` выпускается Unity Hub один раз, Editor ставить не нужно.
   Официальные доки GameCI: <https://game.ci/docs/github/activation>
   **Не хотите вообще заводить секреты?** Варианты без них (Unity Build Automation, разовая сборка
   в Codespace) разобраны в [`docs/BUILD-WITHOUT-SECRETS.md`](docs/BUILD-WITHOUT-SECRETS.md).

2. Запушьте в `main` (или запустите workflow вручную: **Actions → Build Android APK → Run workflow**).
3. Дождитесь зелёного прогона → **Actions → выбранный run → Artifacts → `AndroidBuild`** → внутри `KugooFreeride.apk`.
4. Перенесите APK на телефон и установите (разрешите установку из неизвестных источников).

Требуемая версия Unity — **2022.3.22f1** (`ProjectSettings/ProjectVersion.txt`), URP **14.0.11**.
Сборка идёт в `game-ci/unity-builder@v4` на `ubuntu-latest`, артефакт кладётся через `actions/upload-artifact@v4`.

> `allowDirtyBuild: true` выставлен осознанно: проект сам настраивает себя при открытии редактора
> (`Assets/Editor/ProjectSetup.cs`), из-за чего `ProjectSettings` внутри контейнера становятся «грязными».
>
> PR из форков не получают секреты, поэтому их сборка упадёт на активации лицензии — это ограничение GitHub, не проекта.

### Локальная сборка

* Открыть проект Unity **2022.3.22f1** → `File → Build Settings → Android → Build` (нужен Android-модуль Unity).
* Либо из консоли: `Unity -batchmode -quit -projectPath . -executeMethod ScooterGame.EditorTools.BuildScript.BuildAndroid`
  → `build/Android/KugooFreeride.apk`.

Настройки Android/URP применяются автоматически при открытии проекта (меню `Scooter → Setup Project (Android + URP)`):
IL2CPP, ARM64, minSdk 24, targetSdk auto, OpenGLES3, ландшафтная ориентация, Linear color space,
URP-ассет, Always Included Shaders, сцена в Build Settings.

## 2. Управление

**Android (экранные кнопки):** ◀ ▶ — руль, «ГАЗ», «ПЕРЕД. ТОРМОЗ», «ЗАД. ТОРМОЗ», «WHEELIE» (удержание),
«НОС ↑/↓» — наклон корпуса, «ПРИВОД» — AWD ⇄ RWD (только F3 Pro Max), «РЕЖИМ» — 1/2/3, «СБРОС», «МЕНЮ».

**Клавиатура (для теста в редакторе/android-эмуляторе с OTG):**

| Клавиша | Действие |
|---|---|
| W / ↑ | газ |
| S / ↓ | задний тормоз |
| Left Shift | передний тормоз |
| A / D (←/→) | руль |
| Пробел / Left Ctrl | wheelie (удержание) |
| Q / E | наклон корпуса назад / вперёд |
| Tab | переключить привод AWD ⇄ RWD |
| 1 / 2 / 3 | режим скорости |
| R | сброс на последний чекпоинт |
| Esc | в меню |

## 3. Что в игре

**Самокаты (бесплатные, без доната):**

| | KugooKirin G4 (2026) | Kugoo F3 Pro Max |
|---|---|---|
| Привод | RWD, один задний хаб-мотор | AWD (2 × хаб-мотора), переключение AWD ⇄ RWD |
| Мощность | 2000 Вт (пик 2400) | 2 × 1100 = 2200 Вт |
| Макс. скорость | 70 км/ч | 68 км/ч |
| Режимы | 20 / 40 / 70 | 30 / 51 / 66 |
| Батарея | 60V 20Ah (1200 Вт·ч) | 52V 23.4Ah (1217 Вт·ч) |
| Колёса | 11″ внедорожные | 10″ бескамерные |
| Масса / нагрузка | 37 кг / 120 кг | 32.5 кг / 130 кг |
| Тормоза | передний + задний дисковые | дисковые + электронный тормоз |

**Wheelie по ТЗ:** только выше 15 км/ч, подъём не мгновенный (0.5–1.5 с, зависит от скорости и привода),
зона баланса 25–55°, слабая автокоррекция, критический угол >70° → loop out и падение.
G4 поднимается легче и балансируется хуже; F3 в AWD поднимается тяжелее (передний мотор тянет нос вниз),
но баланс стабильнее, в RWD — как G4. Газ поднимает нос, сброс — опускает, «НОС ↑/↓» подруливает.

**Тормоза:** раздельные передний/задний, электронный тормоз (рекуперация при сбросе газа с подзарядкой батареи).
Длительное торможение только передним на скорости приводит к endo (падение через руль).

**Карты:** «Прямая трасса» (520 м, 5 трамплинов, обочины, отбойники, дневной свет) и
«Город» (улицы, дома, лестницы, перила, парковка, стройка, фонари и движущийся транспорт с фарами).

**Режимы:** свободная езда, Time Attack (5 ворот по порядку, таймер), Freestyle (90 с на очки).
**Трюки:** wheelie, stoppie, прыжки, вращения — очки и комбо-множитель до ×5.

## 4. Структура проекта

```
Assets/
  Scenes/Boot.unity          пустая сцена-загрузчик (всё создаётся кодом)
  Editor/ProjectSetup.cs     автонастройка Android + URP + BuildScript.BuildAndroid
  Scripts/
    Core/                    GameRoot (сессия), GameConfig/VehicleTuning, ввод, камера, bootstrap
    Vehicle/                 ScooterSpec (ТТХ), ScooterFactory (3D-модель), ScooterController (физика), WheelieController
    World/                   MaterialLibrary, MeshUtil, TrackMap, CityMap, Checkpoint, свет, постобработка
    UI/                      UiFactory, Hud (спидометр), TouchControls, MenuScreen, HoldButton
    Tricks/TrickSystem.cs    очки, комбо
    Audio/ScooterAudio.cs    процедурный звук мотора и ветра
.github/workflows/android-build.yml
docs/                        технические заметки, ТТХ, работа с моделями
```

Сцена намеренно пустая: мир, самокат, свет, UI и материалы создаются в рантайме
(`GameBootstrap` → `GameRoot.Initialize()`). Это исключает конфликты GUID/префабов и битые YAML-ассеты.

## 5. Честные отклонения от ТЗ (важно)

1. **Тормозной путь 4 м с 70 км/ч физически невозможен.** 70 км/ч = 19.4 м/с; остановка за 4 м требует
   замедления ≈ 47 м/с² (≈ 4.8 g), а предел сцепления шины — около 1 g. В игре тормоза настроены на пределе
   сцепления (≈ 12 м/с², путь ≈ 16 м с 70 км/ч) — иначе физика Rigidbody + WheelCollider стала бы «рельсовой».
   Константа задаётся в `ScooterSpec.MaxBrakeTorque`.
2. **3D-модели процедурные.** Промпты для AI-генерации из ТЗ лежат в `docs/MODELS.md` и не выполнялись
   (в этой среде нет доступа к 3D-генератору). Модели собираются кодом из примитивов с отдельными объектами
   колёс/руля/подвески/хаб-моторов и PBR-материалами URP — их можно заменить на импортированный меш,
   см. `docs/MODELS.md`.
3. **Батарея расходуется ускоренно** (×6) — иначе полный заряд при 70 км/ч хватало бы на ~45 минут.
   Множитель: `GameConfig.BatteryDrainMultiplier` (1 = реалистично).
4. **Физика баланса аркадная.** Настоящий двухколёсный самокат падает без райдера; в игре работает
   искусственный «балансир» (PD-регулятор крена) с настраиваемыми коэффициентами в `VehicleTuning`.
   Без него игра была бы непроходимой. Wheelie-углы, зоны и тайминги подъёма соответствуют ТЗ.
5. **CI не запускался в этой среде** — нет Unity и секретов лицензии. Код проверен статически
   (парсер C#, сверка всех вызовов и сигнатур, YAML/JSON-валидация), но первый прогон Actions может
   потребовать подстройки (см. `docs/TECHNICAL.md`, раздел «Риски»).
6. **Подпись APK — debug** (ставится на устройство, но не для Google Play). Для публикации нужен
   собственный keystore и `androidExportType: androidAppBundle`.

## 6. Производительность (Android)

* Процедурные материалы и текстуры 128×128 (генерируются в рантайме), PBR-параметры вместо тяжёлых карт.
* Постобработка: bloom всегда; motion blur + DOF только при `systemMemorySize ≥ 2600 МБ`.
* Отключены тени у точечных источников, у солнца — soft shadows, дистанция теней 70 м.
* Ограничение: `Application.targetFrameRate = 60`, VSync выключен, экран не гаснет.
* **LOD сознательно не используется**: процедурные модели низкополигональные, LOD-группы нечего упрощать.
  При замене на меши 15–40k трис добавьте `LOD Group` и убедитесь, что `Shader` не вырезан
  (см. `Always Included Shaders` в `docs/TECHNICAL.md`).

Тюнинг качества: `GameConfig.PostProcessingEnabled`, `Assets/Editor/ProjectSetup.cs` (`m_ShadowDistance`, `m_MSAA`).
